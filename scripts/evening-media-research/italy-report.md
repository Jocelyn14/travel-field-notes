# Italy venue-media research report

- Input rows: 77
- Verified reusable venue photos: 15
- Needs illustration: 62
- Verified source domains: `commons.wikimedia.org` for identity/license pages; `upload.wikimedia.org` for direct assets
- Verification date: 2026-08-10

## Verification method

Each venue name received a bounded exact-name Wikimedia Commons API discovery pass. Exact-looking matches were manually checked on their file pages for venue identity, explicit reusable license or public-domain dedication, creator credit, and original asset URL. Official venue/media pages were eligible only with explicit reuse rights; none supplied a stronger reusable result for this batch. Google and Tripadvisor were treated as discovery/view-only, and no user photo was downloaded.

## Ambiguous and rejected cases

- `it-a-bourbon-water` names the Morelli-specific Galleria Borbonica route; licensed files identified Galleria Borbonica generally, not that route, so it remains `needs-illustration`.
- `it-a-st-pauls-opera` and `it-a-marcello` use exact photographs of the physical venues named by the event listings; the event branding itself is not claimed to be pictured.
- Generic classes, cruises, and walking tours did not resolve to a unique physical venue with reusable media.
- Homonyms such as “Grano” and “The Court” returned unrelated Commons subjects and were rejected.
- Neighborhood and nearby-landmark photographs were rejected even when geographically close.
