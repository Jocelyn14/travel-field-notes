# Practical Travel Desk Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add destination-specific first-visit, resource, etiquette/festival, and emergency information before the checklist heading.

**Architecture:** Store the content in each generated `Trip.practicalInfo`, validate it in the existing trip validator, and render it with one focused view helper. Reuse existing safe external-link behavior and add only scoped responsive CSS.

**Tech Stack:** Native ES modules, generated JSON, CSS, Node test runner, Playwright browser tests, Service Worker cache.

## Global Constraints

- Display order is essentials, resources, customs/festivals, emergency contacts.
- Official-source contacts are verified on 2026-08-11.
- External resources use HTTPS; telephone actions use `tel:` generated by the view.
- Italy and Tokyo remain independent destination pages.
